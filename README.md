# Webo — ويبو

تطبيق Windows لبناء مواقع متعددة الصفحات بصريًا من غير كود (C# / WinUI 3). هذا **إصدار مبكر 0.2.0** (المرحلة الأولى من التنفيذ).

## ما يعمل في هذا الإصدار (مكتوب، وسيُتحقق منه بالبناء والتجربة على Windows)

- واجهة عربية/إنجليزية (RTL/LTR) بخط **IBM Plex Sans Arabic** (ترخيص SIL OFL، مضمَّن في `Assets/Fonts`)، وثيم فاتح/داكن/مثل النظام.
- شاشة رئيسية: مشروع جديد، فتح مشروع، المشاريع الأخيرة (الإزالة من القائمة لا تحذف ملفات).
- إنشاء مشروع (اسم، نوع الموقع، لغة الموقع، مكان الحفظ) داخل مجلد جديد فقط — لا يستبدل أي مجلد موجود.
- هيكل المحرر: قائمة الصفحات (إضافة / إعادة تسمية / تعيين رئيسية / حذف)، أحجام المعاينة (كمبيوتر/تابلت/موبايل)، حفظ ذري مع نسخة `.bak`، وحفظ تلقائي كل 15 ثانية.
- الإعدادات: اللغة، الثيم، **أيقونة التطبيق** (3 خيارات، الافتراضية الداكنة، يُحفظ المعرّف وليس المسار)، واختصارات يدير Webo ما أنشأه منها فقط وبعد موافقتك.
- برنامج تثبيت (Inno Setup) لكل مستخدم بدون صلاحيات مدير، وإزالة البرنامج لا تحذف مشاريعك.

## ما لم يُنفَّذ بعد (مذكور بوضوح في الواجهة)

المحرر البصري الحقيقي ومعاينة الصفحة، التراجع/الإعادة، القوالب والمكونات، الاختبارات، التصدير، معالج النشر.

## البناء

الطريقة المعتمدة: GitHub Actions (`.github/workflows/build.yml`) على `windows-latest`. تُشغَّل يدويًا من تبويب Actions، أو تلقائيًا عند الدفع إلى `main`.
عند دفع وسم مثل `v0.2.0` يُنشر الناتج كـ Pre-release.

محليًا (بعد تثبيت .NET 8 SDK):

```powershell
dotnet publish src/Webo.App/Webo.App.csproj -c Release -r win-x64 -p:Platform=x64 -o out
```

ثم لبناء المثبّت (بعد تثبيت Inno Setup 6): `ISCC.exe /DAppVersion=0.2.0 installer\webo.iss` — الناتج في `dist\`.

## قرارات ثابتة

- أيقونة الملف التنفيذي والمثبّت ثابتة (الداكنة)، ولا تتغير من الإعدادات (D2).
- لا يعدّل Webo اختصارًا لم ينشئه بنفسه (D3). اختصارات المثبّت تبقى كما هي.
- الأيقونات في `Assets/Brand/derived` نسخ مشتقة للمراجعة من الملفات الأصلية؛ الأصول الأصلية لم تُعدَّل.
- الألوان الزرقاء/الكحلية للواجهة مأخوذة من لوجو Webo، والتصميم قابل للتعديل لاحقًا.
- يحتوي المثبّت على واجهة إنجليزية فقط حاليًا (ترجمة Inno العربية غير الرسمية لم تُضف).
