# نموذج Webo التجريبي لأيقونة التطبيق (D9)

نموذج اختبار صغير وليس كود المنتج. هدفه الإجابة بالتجربة عن أسئلة القسم 24 من وثيقة المتطلبات: أي مواضع الأيقونة تتغير فعليًا على Windows، وأيها يحتاج إعادة تشغيل أو إعادة إنشاء اختصار.

## حالة الكود (مهم)

كُتب هذا المشروع **دون بنائه أو تشغيله**، لأن بيئة العمل لا فيها Windows ولا .NET SDK. لذلك:

- قد يحتاج بناؤه الأول إلى تصحيح بسيط (أرقام إصدارات الحزم في `WeboIconSpike.csproj` نقطة بداية، ويحدّثها NuGet).
- أي نتيجة لم تُختبر على Windows حقيقي لا تُعتبر مؤكدة.

## المتطلبات

- Windows 10 أو 11 (للاختبار الجاد جرّب الاثنين، وكل إصدار Windows 10 متاح لديك).
- Visual Studio 2022 مع حمل **.NET desktop development** وقوالب Windows App SDK، أو .NET SDK 8 مع أدوات Windows App SDK.

## البناء والتشغيل

```powershell
cd webo-icon-spike
dotnet build -c Release -p:Platform=x64
.\bin\x64\Release\net8.0-windows10.0.19041.0\win-x64\WeboIconSpike.exe
```

التطبيق غير معبأ (بدون MSIX) ومستقل (لا يحتاج تثبيت Windows App SDK).

## الاختبار

لكل نظام (Windows 10 وWindows 11)، سجّل النتيجة في القائمة المنسدلة بجانب كل موضع، ثم اضغط **تصدير النتائج (JSON)** وأرسل الملف:

1. **نافذة التطبيق وشريط العنوان:** غيّر الاختيار بين الأيقونات الثلاث. هل تتغير أيقونة شريط العنوان فورًا؟ (تخصيص شريط العنوان موثّق كمتاح في Windows 11 فقط.)
2. **زر التطبيق في شريط المهام:** هل تتغير أثناء التشغيل؟ السجل سيوضح هل `SetTaskbarIcon` موجودة في هذا الإصدار أم لا (`N/A`).
3. **التطبيق المثبّت في شريط المهام:** ثبّت التطبيق يدويًا من زر الشريط ثم غيّر الاختيار. هل تتغير أيقونة الاختصار المثبّت أم تبقى القديمة؟
4. **الملف التنفيذي:** افتح مجلد الإخراج في مستكشف الملفات. المتوقع أن تبقى الأيقونة الداكنة ثابتة مهما اخترت (القرار D2).
5. **اختصار سطح المكتب:** اضغط الزر ووافق على الرسالة، ثم غيّر الاختيار واضغطه مرة أخرى. هل تتحدث الأيقونة؟ وإن لم تتحدث، جرّب زر **إخطار الـ Shell** وسجّل هل تغيّرت.
6. **اختصار قائمة Start:** كالسابق.

## قواعد الأمان في النموذج

- لا يعدّل أي اختصار لم ينشئه بنفسه (يتعرف عليها بعلامة في الوصف)، ويطلب موافقتك قبل أي إنشاء أو تحديث.
- يحفظ **معرّف** الأيقونة فقط في `%LOCALAPPDATA%\WeboIconSpike\settings.json`، لا مسار ملف.
- لا يغيّر ملفات الأيقونات ولا يتصل بالإنترنت.
- يسجّل ما أرجعته الواجهات البرمجية، ولا يعرض أي رسالة نجاح بصري. الحكم البصري لك.

## الأيقونات المستخدمة

النسخ في `Assets/Brand/derived/icons/` مشتقة **للمراجعة** من الملفات الأصلية (قص بخلفية شفافة وتوحيد الحجم، وحد وظل خفيف للنسخة الفاتحة). الملفات الأصلية لم تُعدَّل.
